# Sports Digital Network - Website

## Fresh Build - Production Ready

A completely rebuilt, professional website for Sports Digital Network (SDN) designed to help sell advertising and attract venue partners.

---

## ✨ Key Features

### Design & Brand
- **Clean, Professional Aesthetic**: Sports-oriented design with distinctive Bebas Neue headlines + Work Sans body text
- **Consistent Branding**: Navy (#003366), Red (#CC0000), Orange (#FF6600) color palette throughout
- **White Logo on Dark Nav**: SDN-Light.png on navy navigation for perfect visibility
- **Fully Responsive**: Works beautifully on desktop, tablet, and mobile

### Content Strategy
- **Emotion-First Messaging**: "Where Community Comes Together" positioning
- **Community Focus**: Emphasizes the local media gap and community gathering places
- **Clear Stats**: 3.6M weekly visits, 100+ venues, 35M impressions/week, 350 ad plays/day
- **Dual Audience**: Separate content for National and Local advertisers

### Page Structure
1. **Home** - Hero with stats, insight section, venue showcase, strong CTA
2. **About** - Story, values, partnership mindset
3. **Advertisers** - **National section FIRST**, then Local section (as requested)
4. **Venues** - Partnership benefits, revenue opportunity
5. **Resources** - Articles (live), Case Studies (coming soon), Gallery (your venue photo)
6. **Contact** - Form + direct contact methods

## 🚀 Deployment Instructions

### Option 1: Vercel (Recommended)
1. Create new GitHub repository
2. Upload all 6 HTML files to the repository root
3. Connect repository to Vercel
4. Deploy - that's it!

### Option 2: Any Static Host
These files work on:
- Netlify
- GitHub Pages
- AWS S3 + CloudFront
- Any web server

Just upload the 6 HTML files to your hosting root directory.
